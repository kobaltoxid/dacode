# Template Use

Choose one page template that matches the reader’s goal. Keep its useful sections and delete the rest. Do not fill every placeholder just to preserve the template’s shape.

- `concept.md` explains a system or behavior.
- `how-to.md` completes one task.
- `tutorial.md` teaches a larger outcome through steps.
- `reference.md` records exact options or behavior.
- `system-design.md` documents architecture and its primary interaction flow.
- `diagram.md` adds one focused D2 diagram to a page in `docs/`.
- `chart-page.md` explains a chart whose editable source is stored in `docs/charts/`.
