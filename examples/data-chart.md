# Example: Documentation issue count

These synthetic values show the shape of a simple chart source. They are not measurements from a real project.

- **Measure:** Open issues, count
- **Coverage:** Three documentation page types
- **Period:** Illustrative only
- **Source:** Synthetic values in [`data-chart.json`](data-chart.json)
- **Chart source:** [`data-chart.json`](data-chart.json)

The JSON file is the editable Vega-Lite specification. A publishing project should render it to SVG with a pinned toolchain and embed that SVG here. Do not treat a manual export as the source.
